# phrog
Super low cost spectrophotometric ph sensor

What is the purpose of the pHrog?

To be an educational kit that people can build themselves and use to learn how to make a spectrophotometric measurement.

It should be able to do basic spectrophotometric measuremtns and be able to get pH to +-0.1 units. That is the goal. 

It should be easy to build, and be repairable.

Still under early development
